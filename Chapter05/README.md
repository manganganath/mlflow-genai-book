# Chapter 5: MLflow Tracing for GenAI Application Observability

This chapter makes the Unity Airways assistant interpretable by instrumenting MLflow
Tracing so every request becomes a replayable story, helping you diagnose quality
issues and understand latency and cost drivers.

## In this chapter
- Understanding MLflow Tracing (Trace, Span)
- Instrumenting Traces (Automated Tracing, Manual Tracing)
- Querying Traces

## In this folder
- `chapter05_walkthrough.ipynb` — demonstrates trace and span concepts,
  automated and manual instrumentation, and querying captured traces.

## Before you start
See the [repository README](../README.md) for prerequisites and setup. Run the
[`Appendix/data_ingestion`](../Appendix/data_ingestion) notebooks first to build the
Unity Airways FAQ vector search index used from Chapter 4 onward.
