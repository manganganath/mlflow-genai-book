# Chapter 3: Prompt Engineering with MLflow

This chapter treats prompts as first-class, versioned assets. You design prompts for
the Unity Airways assistant that stay stable under real user input, manage them in the
MLflow Prompt Registry, and evaluate changes with evidence rather than intuition.

## In this chapter
- Fundamentals of Prompt Engineering
- Managing Prompts with the MLflow Prompt Registry
- Using Prompts in Code
- Evaluating and Comparing Prompt Versions
- Prompt Optimization
- Integrating Prompts into Applications

## In this folder
- `chapter03_walkthrough.ipynb` — hands-on walkthrough covering prompt registration,
  versioning with aliases, evaluation, optimization, and integration into the assistant.

## Before you start
See the [repository README](../README.md) for prerequisites and setup. Run the
[`Appendix/data_ingestion`](../Appendix/data_ingestion) notebooks first to build the
Unity Airways FAQ vector search index used from Chapter 4 onward.
