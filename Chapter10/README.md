# Chapter 10: Unifying GenAI Systems with MLflow

This closing chapter looks ahead at how MLflow helps unify increasingly complex GenAI
systems, using MLflow Traces as a shared integration artifact and covering the tools
that connect the Unity Airways assistant to a broader ecosystem.

## In this chapter
- MLflow Traces as the Shared Integration Artifact
- OpenTelemetry for Cross-Stack Tracing
- MLflow Agent Server
- MLflow MCP
- MLflow Skills for Coding Agents
- Third-Party Judges
- Road Ahead

## In this folder
- `chapter10_walkthrough.ipynb` — demonstrates cross-stack tracing with
  OpenTelemetry, the MLflow Agent Server and MCP, MLflow Skills, and third-party judges.

See the [repository README](../README.md) for prerequisites and setup. Run the
