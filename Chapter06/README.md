# Chapter 6: Evaluating GenAI Applications with MLflow

This chapter replaces vibe checks with evidence. You build evaluation datasets, define
code-based and LLM-judge scorers, incorporate human feedback, and run consistent
evaluations to make promotion decisions for the Unity Airways assistant.

## In this chapter
- The MLflow Evaluation Framework
- Creating and Managing Evaluation Datasets
- Designing and Managing Scorers (Code-Based Scorers, LLM Judges)
- Running and Comparing Evaluations in MLflow
- Capturing Human Feedback

## In this folder
- `chapter06_walkthrough.ipynb` — walks through evaluation datasets, scorer design,
  running and comparing evaluations, and capturing human feedback.

## Before you start
See the [repository README](../README.md) for prerequisites and setup. Run the
[`Appendix/data_ingestion`](../Appendix/data_ingestion) notebooks first to build the
Unity Airways FAQ vector search index used from Chapter 4 onward.
